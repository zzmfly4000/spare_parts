# 设备备件管理系统用户手册

## 系统概述
设备备件管理系统是一个用于管理工厂设备备件的综合性管理系统，包含备件信息管理、库存跟踪、出入库操作、低库存报警、数据导入导出、库位管理等核心功能。

## 首页功能说明
系统首页提供了一个直观的仪表板界面，包含以下主要功能区域：

### 系统概览
- 显示总备件数、总库位数和低库存备件数量
- 实时显示系统时间和状态信息

### 快速操作
- **智能入库**: 快速添加备件或增加库存
- **备件出库**: 直接访问备件列表进行出库操作
- **库位管理**: 管理库位和库存分布
- **备件查询**: 搜索和查找特定备件

### 低库存预警
显示当前库存低于最低库存水平的备件列表，帮助及时补充库存。

### 最近活动
显示系统最近的操作记录，包括入库和出库活动。

## 核心功能模块

### 1. 备件管理
- 备件信息的增删改查操作
- 备件搜索和筛选功能
- 库存状态实时监控

### 2. 库位管理
- 库位信息维护
- 库位状态跟踪
- 库位使用率统计

### 3. 操作记录
- 备件出入库记录
- 操作历史查询
- 智能入库功能
